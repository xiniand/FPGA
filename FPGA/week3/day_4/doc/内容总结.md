# day_4 内容总结

## 概述

本练习在分频器基础上进行**参数化与顶层自动选择**：用 `parameter` 配置分频系数，把偶分频与奇分频分别封装成模块，再由顶层根据系数奇偶自动例化对应分频器；同时继续练习按键消抖 + LED 循环点亮。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| fpq_o.v | fpq_o | 参数化**偶分频器**：`delay` 可配置，计数器在 (delay-1)/2 与 delay-1 处翻转 `clk_out` |
| fpq_j.v | fpq_j | 参数化**奇分频器**：上升沿翻转 `clk_out_1`、下降沿翻转 `clk_out_2`，`assign clk_out = clk_out_1 \| clk_out_2` 合成 50% 占空比输出 |
| fpq.v | fpq | 奇/偶兼容分频器：`delay=3`，同一模块内用 `delay%2` 判断走奇分频（双沿相或）或偶分频路径 |
| fpq_top.v | fpq_top | **分频顶层**：`generate` + `if(delay%2)` 根据参数奇偶自动例化 `fpq_j_u`（奇）或 `fpq_o_u`（偶） |
| freq_o.v | freq_o | 偶分频（`NUMBER=4`，12.5MHz）：计数器 + 两处翻转 |
| freq_j.v | freq_j | 奇分频（`NUMBER=3`，约 16.7MHz）：上升沿 `out_clk1` 与下降沿 `out_clk2` 相或 |
| freq_top.v | freq_top | **分频顶层变体**：同时例化 `freq_o_inst` 与 `freq_j_inst`，`assign clk_out = (NUMBER%2) ? out_j : out_o` 用条件表达式选择输出 |
| key.v | key | 按键消抖：`delay_1=999_999`，按下计数、满后输出单拍 `flag` |
| led.v | led | LED 循环：`en` 由 `key` 翻转（开关），0.5s 计数器计满后 `led <= {led[2:0], ~led[3]}` 移位循环点亮 |
| top_led.v | top_led | **LED 顶层**：`delay/delay_1` 参数化，例化 `key_u`（消抖）与 `led_u`（循环），按键切换 LED 启停 |

## 整体功能说明

本 day 展示了分频器的两种参数化组织方式：`fpq_top` 用 `generate` 在编译期按 `delay%2` 静态选择奇/偶分频模块，`freq_top` 则把两种分频器都例化、用三目表达式动态选择输出——两者都能根据分频系数自动得到正确分频时钟。`top_led` 构成独立的“按键消抖 → LED 循环”小系统：按键产生消抖脉冲翻转使能 `en`，使 LED 在 0.5s 节奏下循环点亮或暂停。整体体现“参数化、可配置、顶层组合子模块”的设计思路。
