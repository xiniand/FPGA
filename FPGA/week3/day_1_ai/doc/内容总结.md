# day_1_ai 内容总结

## 概述

本练习实现一个完整的**交通灯控制系统**：50MHz 时钟分频出 1Hz/1kHz，交通灯状态机控制南北/东西方向红黄绿灯循环，并把倒计时通过 4 位 7 段数码管动态扫描显示出来，支持紧急按钮强制红灯。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| clk_div.v | clk_div | 时钟分频：50MHz 二分频后再计满 `CNT_1HZ=25_000_000` 得到 1Hz 秒脉冲、计满 `CNT_1KHZ=25_000` 得到 1kHz 扫描脉冲（分频时钟翻转输出） |
| traffic_fsm.v | traffic_fsm | 交通灯状态机：`NS_GREEN(30s)→NS_YELLOW(5s)→EW_GREEN(20s)→EW_YELLOW(5s)` 循环；单进程写法统一更新 state 与递减 timer；`emergency=1` 时强制红灯且暂停计时；组合输出 `light_ns/ew[G,Y,R]` 与两方向倒计时 |
| seg_driver.v | seg_driver | 数码管驱动：1kHz 下 4 位动态扫描；把 0~59 秒拆成十位/个位 BCD；case 译出共阳极段码（低有效）与位选（低有效），物理排列 S1~S4 对应 NS十位/NS个位/EW十位/EW个位 |
| top.v | top | **顶层模块**：例化 `u_clk_div`、`u_traffic_fsm`、`u_seg_driver` 组成完整系统；将板级低有效紧急按键电平转换（`~emergency`）后送给 FSM |

## 整体功能说明

系统按“时钟分频 → 状态机 → 显示”三级流水组织：`clk_div` 同时为状态机提供 1Hz 节拍、为数码管提供 1kHz 扫描；`traffic_fsm` 以单进程状态机管理红黄绿灯状态与倒计时，紧急模式下所有灯强制红灯、计时暂停；`seg_driver` 将南北/东西两方向倒计时实时显示在 4 位数码管上（红灯方向显示“还需多久变绿”，绿灯/黄灯方向显示剩余秒数）。整个设计参数化、风格规范（低有效复位 `rst_n`、`negedge rst_n` 异步复位、组合/时序逻辑分离），是典型的可综合交通灯综合实例。
