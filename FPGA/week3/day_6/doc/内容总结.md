# day_6 内容总结

## 概述

本练习在按键切换 LED 灯效的基础上引入**蜂鸣器**，实现“按键切换三种灯效（流水/跑马/闪烁）”与“蜂鸣器播放一段简谱旋律”两个可综合设计，并练习用三段式状态机组织灯效控制。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| key.v | key | 按键消抖：`delay=999_999`，按下计数满后输出单拍 `key_out` |
| led.v | led | 按键切换三灯效：三段式状态机，`key` 脉冲依次切换 `FLOW_LED→PAOMA_LED→SHAN_LED`；0.5s 计数器 `end_cnt_led` 驱动对应灯效（流水左移 / 跑马反折 / 闪烁取反）移位，按状态输出 |
| led_ztj.v | led_ztj | 自动轮换版状态机：`FLOW_LED→PAOMA_LED→SHANSHUO`，4s 计数器触发状态跳转、0.5s 计数器驱动灯效节奏，无需按键自动循环 |
| beep.v | beep | 蜂鸣器：内置音符频率参数 `L1~L7`（低音 1~7），0.5s 换一个音符循环播放；用 `frq_data>>1` 作 50% 占空比，`l_cnt` 计满一个音符周期翻转输出，实现发声 |
| top_led.v | top_led | **顶层模块**：例化 `key_u`（消抖）与 `led_u`（灯效），按键按下经消抖后切换 LED 灯效 |

## 整体功能说明

`top_led` 构成“按键控制灯效”系统：按键经 `key` 消抖成脉冲，`led` 模块的三段式状态机根据按键脉冲在流水灯、跑马灯、闪烁三种灯效间循环切换，每 0.5s 更新一次灯效。`led_ztj` 是对同一灯效的状态机改写——由 4s 定时器自动轮换而非按键控制。`beep` 独立实现音乐播放：按 0.5s 节拍依次切换低音 1~7 的频率参数，通过计数比较在 `l_cnt` 计到半周期时置高、计满整周期时置低，输出占空比 50% 的方波驱动蜂鸣器发声，可上板播放一段简谱。
