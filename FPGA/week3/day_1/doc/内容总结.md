# day_1 内容总结

## 概述

本练习覆盖 FPGA 基础逻辑设计：组合逻辑（与/或/非门、2-1 多路选择器、2-4 译码器）、计数器、分频器、按键消抖与 LED 控制，并通过顶层模块把按键消抖与 LED 翻转串联成一个完整小系统。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| men.v | men | 基本门电路演示：`C = X & Y`（与门）、`S = X \| Y`（或门）、`Z = ~X`（非门） |
| duolu.v | duolu | 2-1 多路选择器：`sel=0` 输出 `in_a`，`sel=1` 输出 `in_b` |
| dc2_4.v | dc2_4 | 2-4 译码器：由 `case(sw)` 把 2 位输入译成 4 位独热码输出到 LED |
| cnt.v | cnt | 3 位计数器：`rst==0` 清零，计到 `sj` 后回 0 循环 |
| fp_ztj.v | fp_ztj | 分频器（状态机风格）：`TIME=24_999_999`，每计满一个周期输出 1 拍的 2Hz 脉冲 `clk_out` |
| key.v | key | 按键消抖：按键按下（`key==0`）持续计数 `delay=1_000_000`，满后输出 1 拍 `flag` 脉冲 |
| key_ztj.v | key_ztj | 按键消抖的变体，与 `key` 功能相同（`delay=1_000_000`） |
| led.v | led | LED 控制：`key==1` 时每个时钟沿 `led <= ~led`（翻转），配合消抖脉冲逐次翻转 |
| led_ztj.v | led_ztj | 三段式状态机示例：S0/S1/S2 三个状态，由 4s 计数器触发状态跳转，0.5s 计数器驱动 LED 节奏（该文件 LED 输出逻辑未写完） |
| top_led.v | top_led | **顶层模块**：例化 `key_u`（消抖）与 `led_u`（翻转），按键按下 → 产生消抖脉冲 → LED 翻转一次 |

## 整体功能说明

`top_led` 将按键消抖与 LED 翻转两级串联：用户按一次键，`key` 模块消抖后产生单拍 `flag` 脉冲，`led` 模块据此把 4 位 LED 取反一次，实现“按一下翻一次”的效果。其余 `men`、`duolu`、`dc2_4`、`cnt`、`fp_ztj` 等为独立的组合/时序基础模块，供单独验证基础语法与电路结构（门电路、选择器、译码器、计数器、分频）。`led_ztj` 与 `fp_ztj` 属于状态机风格练习，其中 `led_ztj` 的 LED 输出段代码不完整，尚未实现实际点亮效果。

> 注意：`led.v` 中 `key==1` 每拍都翻转，若直接接按键电平会快速翻转，必须经 `key` 模块消抖成脉冲后再驱动，这正是 `top_led` 串联两者的原因。
