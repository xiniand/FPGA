# day_3 内容总结

## 概述

本练习重点为**分频器设计**（偶分频、奇分频）、**边沿检测**（上升沿/下降沿/双边沿）与 2-4 译码、LED 闪烁的综合运用，并包含两个顶层模块分别演示“边沿检测 + 译码”与“分频 + LED 闪烁”的组合。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| posedge.v | posedge | 边沿检测：对单信号 `a` 打一拍 `a_dly`，用 `a & ~a_dly`、`~a & a_dly`、`a ^ a_dly` 分别输出上升沿/下降沿/双边沿脉冲 |
| dc2_4.v | dc2_4 | 边沿检测 + 2-4 译码：对 `a_1/a_2` 各自做上升/下降/双边沿检测；用两信号的边沿置位/复位寄存器 `a/b`，再由 `{a,b}` 译出 4 位独热码 `A` |
| key.v | key | 按键消抖：按键按下持续计数 `delay=1_000_000`，满后输出单拍 `flag` 脉冲 |
| fpq.v | fpq | 偶分频器：`delay=2`，计数器计满 (delay-1)/2 与 delay-1 时翻转 `clk_out`，输出 2 分频 |
| fpj.v | fpj | 奇分频器：用上升沿与下降沿两路时钟各自翻转再相或输出（`delay=3`，3 分频）；文件后半部分代码不完整 |
| fpq_led.v | fpq_led | LED 闪烁：`delay_1=6_250_000` 计数器计满翻转一次 4 位 LED |
| fpq_ledd.v | fpq_ledd | 偶分频 + LED：先把时钟 2 分频出 `clk_out`，再在分频时钟域计数 `NUMBER=25_000_000` 驱动 LED 翻转 |
| freq.v | freq | 4 分频 + 定时：`NUMBER=4` 分频出 12.5MHz `clk_out`，再计 `CNT_NUM=12_499_999` 翻转 LED（文件开头为被注释掉的纯 4 分频版本） |
| top_dc2_4.v | top_dc2_4 | **顶层模块 1**：例化 `dc2_4_u`，把按键/拨码输入送给边沿检测译码模块，输出各边沿脉冲与译码结果 `A` |
| top_fpq.v | top_fpq | **顶层模块 2**：例化 `fpj_u`（分频）与 `fpq_led_u`（LED 闪烁，`delay_1` 参数化），分频时钟作为 LED 模块时钟驱动闪烁 |

## 整体功能说明

该 day 围绕两条主线：一是**时序边沿处理**——`posedge`/`dc2_4` 通过打一拍寄存实现上升/下降/双边沿脉冲检测，`top_dc2_4` 把按键输入经边沿检测后译码点亮不同 LED；二是**分频驱动外设**——`fpq`/`fpj`/`freq`/`fpq_ledd` 用计数器按分频系数翻转时钟，`top_fpq` 用分频时钟驱动 LED 以可见速度闪烁。`key` 为通用按键消抖模块，可接入边沿检测以消除抖动误触发。

> 注意：`fpj.v`、`freq.v` 等文件内部保留了大量被注释掉的备选写法，属课堂演示/练习过程产物；其中 `fpj.v` 存在未声明的 `cnt` 引用且逻辑不完整，若需综合应使用 `fpq.v`/`freq.v` 或改写修正。
