# day_5 内容总结

## 概述

本练习实现**多种 LED 灯效的切换**：流水灯（循环点亮）与跑马灯（带反折的循环）两种效果，通过按键消抖后的信号翻转使能 `en` 来选择显示哪一种；另有状态机 FSM 练习（三段式状态机控制灯效自动轮换、序列检测状态机示例）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| key.v | key | 按键消抖：`delay_1=999_999`，按下计数满后输出单拍 `flag` |
| liushui.v | liushui | 流水灯模块：`en==0` 时 0.5s 计数器计数，计满 `led <= {led[2:0], led[3]}` 左移循环点亮 |
| paoma.v | paoma | 跑马灯模块：`en==1` 时计数，计满 `led <= {led[2:0], ~led[3]}` 移位并在移出端反相，形成来回跑动效果 |
| led.v | led | 整合版：内部含消抖 + `en` 翻转，同时生成流水/跑马两种灯效，`assign led = (en==0)? led_l : led_m` 切换 |
| led_1.v | led_1 | 单文件整合版：消抖 → `en` 翻转 → 两个 0.5s 计数器分别驱动流水/跑马 → `assign led = en ? led_liu : led_pao` 选择 |
| led(7).v | led | 练习版整合模块（文件名含括号）：消抖后 `key_out` 翻转 `key_en`，`key_en=1` 选流水灯、`key_en=0` 选跑马灯（含 testbench 时间刻度头） |
| top_led.v | top_led | **顶层模块**：`en` 由 `flag` 翻转；参数化例化 `key_u`、`paoma_u`、`liushui_u`，`assign led = (en==0)? led_liu : led_pao` 输出 |
| led_ztj.v | led_ztj | 三段式状态机：`FLOW_LED→PAOMA_LED→SHANSHUO` 三个灯效状态，4s 计数器触发状态跳转、0.5s 计数器驱动灯效节奏，自动循环（部分变量名存在笔误，代码不完整） |
| ztj.v | ztj | 状态机示例：两段式与三段式写法实现“101”序列检测（`data_in/data_out` 未在端口声明，属练习草稿） |

## 整体功能说明

本 day 的核心是“一个按键切换两种灯效”：`top_led` 中按键经 `key` 消抖产生脉冲 → 翻转使能 `en` → `liushui`（流水）与 `paoma`（跑马）各自独立以 0.5s 节奏移位 → 顶层用 `en` 做二选一输出，按一下切流水灯、再按一下切跑马灯。`led.v`/`led_1.v`/`led(7).v` 是把同样功能写进单个文件的整合/练习变体，便于对照。`led_ztj.v` 与 `ztj.v` 属于状态机进阶练习，前者尝试用三段式 FSM 自动轮换灯效，后者练习序列检测状态机。

> 注意：`led(7).v` 文件名含括号，在部分工具链（Makefile/工程文件列表）中需注意转义；`led_ztj.v` 存在未声明信号与拼写笔误，当前不可直接综合。
