# week5_8.10\day_4 内容总结

## 概述

本 day 练习 **PLL 多时钟与异步 FIFO 读写**：例化 `clock` PLL IP 产生 5 路不同频率时钟（c0~c4），用 50MHz 写时钟、PLL 输出的 25MHz 读时钟，演示跨时钟域下**异步 FIFO**（`fifo_data` IP，8bit×256）的写入/读出及满、空、水位标志的使用。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 顶层：例化 PLL `clock` 出 5 路时钟；计数器 0~1023，`cnt≤500` 打开写使能、数据自增写入 FIFO（写时钟 `clk`），`cnt>500` 后切换为读（读时钟用 PLL 的 `c0_25`=25MHz），演示写快读慢/跨时钟域，引出 full/empty/usedw 标志 |
| top.v.bak | top | 早期备份版：同步 FIFO `fifo_data_t`（8bit×256），当前注释未用 |

## 整体功能说明

顶层用 `clk` 计数 0~1023 模拟读写切换：前半段数据自增写入 FIFO，后半段从 FIFO 读出。读侧时钟来自 PLL 的 `c0_25`（25MHz），与写侧 50MHz 不同，借此观察**异步 FIFO** 跨时钟域的读写时序与满/空/水位标志（`usedw`）。注释中给出了读写时序要点（读使能后下一拍出数、数据先备好再读）。IP：`clock`（c0~c4 = 25/50/100/150/200MHz）、`fifo_data`（8bit×256 异步 FIFO）。
