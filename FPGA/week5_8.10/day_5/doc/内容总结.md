# week5_8.10\day_5 内容总结

## 概述

本 day 练习 **UART 接收（带偶校验）→ 数码管显示 + LED 校验错误指示**：用 `brg` 产生 9600 波特率 tick，`rx` 在起始位下降沿后按位中点采样，并在 PARITY 态核对偶校验，数据送 2 位动态数码管显示、校验错误接 LED。`tx.v` 为未完成的草稿（含语法问题）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| brg.v | brg | 波特率发生器：50MHz/9600，每 bit 计 5207 周期出 tick |
| rx.v | rx | 接收器：二级打拍 + 下降沿检测 + bit 中点采样，状态机 IDLE/START/RECX/PARITY/STOP，输出 parity_error |
| rx_0.v | rx | 早期无校验版本（IDLE/START/RECX/STOP） |
| tx.v | tx | 发送器草稿：IDLE/START/DATA/STOP，**当前未完成**（引用未定义 `state`、缺 begin/end、无输出逻辑） |
| dt_smg.v | dt_smg | 2 位动态数码管扫描（5ms 切换，段码含 0~F） |
| top_uart.v | top_uart | 顶层：rx→数码管显示，parity_error→LED，rx_done 引出 |

## 整体功能说明

PC 发一帧（起始 + 8 数据 + 偶校验 + 停止），`brg` 供 tick；`rx` 在 PARITY 态核对偶校验（`parity_error = 校验位 != ^data_rg`），接收数据送 `dt_smg` 两位显示（高/低 4 位），校验错误用 LED 指示。仿真 `parity_test.v` 验证校验逻辑。
