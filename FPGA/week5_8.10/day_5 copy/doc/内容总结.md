# week5_8.10\day_5 copy 内容总结

## 概述

本目录是 day_5 的**简化重写版**——UART 收发（**无校验**），用于与 PC 串口助手联调：拨码设发送数据 + 触发发送，接收完成用 LED 指示。相对主目录，`rx` 去掉 PARITY 态与 parity_error，`tx` 修复为完整状态机，顶层更精简（无数码管）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| brg.v | brg | 波特率发生器 9600bps |
| tx.v | tx | 发送器（完整版）：IDLE/START/DATA/STOP，与 free-running tick 对齐、LSB 先发、出 tx_done |
| rx.v | rx | 接收器（无校验版）：rx_pos/rx_end 中点采样，START 态确认非毛刺，收满 8 位 + 停止位出 rx_done |
| top.v | top | 顶层：brg+tx+rx 整合；拨码 tx_data + tx_star 发送，rx_done 指示接收 |

## 整体功能说明

与主目录 day_5 对比：接收去掉偶校验（无 PARITY 态），发送修复为完整状态机；顶层通过拨码开关设定要发送的数据、触发 `tx_star` 发送，接收完成用 LED 指示。仿真有 `top_test.v`/`test.v` 做收发自测。
