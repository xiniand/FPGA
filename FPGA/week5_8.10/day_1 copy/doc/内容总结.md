# day_1 copy 内容总结

## 概述

本目录为 day_1 的 IP 化/重构版本：同样用 PLL 生成多路时钟、按键切换后驱动数码管计数显示，但源码文件与端口统一带 `_ip` 后缀，复位统一采用低有效 `rst_n`，数码管段选改用时序逻辑输出。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top_ip.v | top_ip | 顶层模块：例化 PLL 时钟 IP（clock，输出 c0~c4 五路时钟）、两个按键消抖模块 key_ip、数码管显示模块 smg_dt；按键控制 key_cnt 循环切换，组合 MUX 选出其中一路时钟作为 clk_save 驱动数码管 |
| key_ip.v | key_ip | 按键消抖模块：两级同步打拍消除亚稳态，计数 TIME_key 周期确认按键按下，输出 key_out 单脉冲，端口为低有效 rst_n |
| smg_dt.v | smg_dt | 数码管显示模块：以 TIME 周期循环计数 0~9，经 ROM IP（rom_data）查表得到数据，按共阴数码管段码用时序逻辑（always @(posedge clk)）译码输出 seg，位选 sel 固定为 6'b000_000 |

## 整体功能说明

顶层例化 `clock`（Altera PLL IP），从 50MHz 输入产生五路时钟：c0=25MHz、c1=100MHz、c2=150MHz（注释说明为改变 90° 相位移）、c3=200MHz、c4=300MHz。两个按键 `key_ip` 经消抖后控制 key_cnt 在 0~4 间循环，组合逻辑 case 选出一路时钟作为 clk_save 驱动 `smg_dt`。`smg_dt` 内以 TIME 周期循环计数 0~9，经 `rom_data`（ROM IP）查表得到数据，再按共阴数码管段码译码输出到 `seg`，位选 `sel` 固定。功能与 day_1 一致——按键切换时钟频率即可观察数码管计数速率变化；本目录主要体现工程重构与命名规范（`_ip` 后缀、低有效 `rst_n`）。

**用到 IP 核**：PLL（clock，五路时钟输出）、ROM（rom_data）。
