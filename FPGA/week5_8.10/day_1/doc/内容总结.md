# day_1 内容总结

## 概述

本练习通过 PLL 时钟 IP 生成多路不同频率的时钟，用按键切换选择某一路时钟来驱动数码管计数显示，从而直观观察不同时钟频率下数码管计数快慢的变化，理解时钟频率对电路行为的影响。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 顶层模块：例化 PLL 时钟 IP（clock，输出 c0~c4 五路时钟）、两个按键消抖模块 key、数码管显示模块 smg；按键控制 cnt 循环切换，组合 MUX 选出其中一路时钟作为 clk_rg 驱动数码管 |
| key.v | key | 按键消抖模块：两级同步打拍消除亚稳态，计数 delay_1（约 20ms）周期确认按键按下，输出 flag 单脉冲 |
| smg.v | smg | 数码管显示模块：以 TIME 周期循环计数 0~9，经 ROM IP（rom_data）查表得到数据，按共阴数码管段码译码输出 dig，位选 sel 固定为 6'b000_000 |

## 整体功能说明

顶层例化 `clock`（Altera PLL IP），从 50MHz 输入时钟产生五路不同频率时钟 c0~c4；两个按键 `key` 经消抖后各自产生 flag 单脉冲，控制 3bit 计数器 cnt 在 0~4 之间循环递增/递减，再通过组合逻辑 case 将 cnt 对应的那一路时钟作为 clk_rg 输出。`smg` 内部以 TIME 周期循环计数 0~9，经 `rom_data`（ROM IP）查表得到 4bit 数据，最后按共阴数码管段码译码驱动 `dig`，位选 `sel` 固定显示单只数码管。由于数码管计数快慢与 clk_rg 频率直接相关，按下按键切换时钟即可看到数码管计数速率随之变化。

**用到 IP 核**：PLL（clock，五路时钟输出）、ROM（rom_data）。
