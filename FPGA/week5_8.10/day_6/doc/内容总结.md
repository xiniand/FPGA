# week5_8.10\day_6 内容总结

## 概述

本 day 综合练习 **UART 收发 + 按键消抖触发发送 + 内部回环自测 + FIFO 缓冲 + 数码管显示**：按键消抖触发 TX 发送一字节，发送线直接接回 RX 形成**回环**，接收数据写入 FIFO（`fifo_data` IP），每 1s 定时读出送数码管显示，偶校验错误接 LED。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| brg.v / tx.v / rx.v | brg / tx / rx | 9600bps；rx 带偶校验（PARITY 态） |
| key.v | key | 按键消抖：20ms 计数 + 两级打拍，输出单脉冲 flag |
| dt_smg.v | dt_smg | 2 位动态数码管 |
| top_tx.v | top_tx | 仅发送顶层（brg+tx） |
| top_rx.v | top_rx | 仅接收顶层（rx+数码管，parity_error→LED） |
| top_uart.v | top_uart | 收发顶层（rx 外部输入→数码管，key 触发发送） |
| top_uart_zh.v | top_uart_zh | 回环顶层：rx 内部接 tx，key 触发→自收→FIFO 存→1s 定时读→数码管 |

## 整体功能说明

核心为**回环自测**：按键消抖出 `flag` 触发 tx 发一字节，发送线直接接回 rx 接收；接收数据写 FIFO（写使能 = rx_done），每 1s 定时读出供数码管显示，偶校验错误接 LED。仿真 `tx_tb.v`、`key_tx_tb.v` 分别验证发送链路与按键触发。关键参数：9600bps、消抖 20ms。
