# day_2 内容总结

## 概述

在 day_1 的基础上引入 RAM 存储：顶层用异步双端口 RAM IP 在写时钟（clk）侧写入一组预置数据、在读时钟（clk_rg，可由按键切换）侧循环读出并经数码管显示；另含一个独立的"数据表"演示模块 smg_watch（写入 10 组数据后停止写入、循环读出显示）及其 testbench。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 顶层模块：例化 PLL 时钟 IP（clock，输出 c0~c4 五路时钟）、两个按键消抖 key、异步双端口 RAM IP（ram_data_2）与数码管 smg；data_num 按主时钟 clk 产生写地址/写数据，rd_addr 按切换后的读时钟 clk_rg 循环读地址，读出的数据经 smg 译码显示 |
| key.v | key | 按键消抖模块：两级同步打拍消除亚稳态，计数 delay_1（约 20ms）周期确认按键按下，输出 flag 单脉冲 |
| smg.v | smg | 数码管段选译码模块：输入 4bit 数据 data，用组合逻辑 case 按共阴数码管段码译码输出 dig，位选 sel 固定为 6'b000_000 |
| smg_watch.v | smg_watch | "数据表/秒表"演示模块：按 TIME 周期把预置的 10 组数据依次写入单时钟 RAM IP（ram_data2），写满（data_num 到 9）后进入停止态关闭写使能，同时 rd_addr 按 TIME 周期循环读地址，读出数据经段选译码循环显示 |
| test_watch.v | test_watch | testbench：使用 `timescale 1ns/1ns`、50MHz 时钟（`always #10 clk = ~clk`），例化 smg_watch 并把 TIME 调小为 24 以缩短仿真时间，`$stop` 结束 |

## 整体功能说明

顶层 `top.v` 中，PLL `clock` IP 输出五路时钟，两个按键经消抖后控制 cnt 在 0~4 间循环，组合 MUX 选出 clk_rg 作为异步双口 RAM（`ram_data_2`）的读时钟（outclock），写时钟（inclock）固定为主时钟 clk。`data_num` 按 clk 循环 0~9 产生写地址与写数据（2/4/6/8/10/12/14/7/9/5），写入 RAM；读侧 `rd_addr` 按 clk_rg 计数循环读出，读出的数据经 `smg` 译码显示在数码管上。由于读时钟频率可由按键切换，体现了"读写时钟不同步、频率可切换"的异步 RAM 典型应用。

`smg_watch.v` 为独立演示模块：用单时钟 RAM IP `ram_data2` 按 TIME 周期依次写入 2、5、7、9、15、10、11、9、7、8 十组数据，写完最后一笔后 data_num 进入停止态（10）并关闭写使能 wr_en，读取侧 rd_addr 循环读出并在数码管上循环显示这组序列（类似秒表/跑表效果）。`test_watch.v` 为其 testbench，单独验证该模块的写满停止与循环显示逻辑。

**用到 IP 核**：PLL（clock，五路时钟输出）、异步双端口 RAM（ram_data_2）、单时钟 RAM（ram_data2）。
