# day_6 内容总结

## 概述

本 day 是**综合性小游戏——"倒计时拆弹"**：数码管显示 40 秒倒计时，玩家拨动 9 位拨码开关并按下确认键；密码正确则"拆除成功"（LED 全亮），密码错误或倒计时归零则"爆炸"（LED 闪烁）。综合了按键消抖、数码管动态显示、状态机、译码比对、LED 特效等前面多天所学内容。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 顶层：整合 1s 倒计时计数、BCD 拆分、三态状态机（00 倒计时/01 成功/10 爆炸）、LED 输出，并例化 key / yima9 / led_boom / dt_smg 各子模块 |
| key.v | key | 按键消抖（改进版）：同步打拍消除亚稳态 + 20ms 计数，用 `flag_r` 寄存器稳定输出单拍脉冲（比组合逻辑输出更规范） |
| yima9.v | yima9 | 9 输入译码比对：当 9 位开关 `sw[8:0]` 等于预设密码 `PASSWORD`（9'b0_1010_1010）时 `match` 输出 1，否则 0 |
| led_boom.v | led_boom | LED 爆炸闪烁：`boom` 使能时以 0.5s 周期整体翻转 4 位 LED（爆炸效果），否则熄灭 |
| dt_smg.v | dt_smg | 数码管动态扫描：接收外部 6 位 BCD（本工程只用个位/十位，其余接 4'd15 显示空白），5ms 轮换 sel 位选，段码显示 0~9 |

## 整体功能说明

`top` 顶层构成一个完整的状态机应用：

- **倒计时**：`cnt_1s` 每 1s 触发一次，`sec` 从 40 递减，`bcd0/bcd1` 用 `%`/`/` 拆成个位/十位供数码管显示；
- **状态机**：`state` 三态——倒计时中（00）：按下确认键后若密码匹配进入"成功"（01），否则进入"爆炸"（10）；若倒计时归零同样进入"爆炸"；成功/爆炸为保持态；
- **子模块配合**：`key` 消抖确认键；`yima9` 比对 9 位拨码与密码；`led_boom` 在爆炸态驱动 LED 闪烁；`dt_smg` 显示剩余秒数；
- **LED 输出**：`assign led = (state==2'b01) ? 4'b1111 : boom_led;`——成功全亮、爆炸闪烁、其余熄灭。

整体逻辑清晰、模块划分合理，是前几日知识点（状态机、分频、消抖、动态扫描、译码）的综合收官练习。低有效异步复位。
