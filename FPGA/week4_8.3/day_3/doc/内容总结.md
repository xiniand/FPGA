# day_3 内容总结

## 概述

本 day 练习**数码管动态显示 + 按键消抖 + 译码器**：包括 6 位数码管动态扫描（`dt_smg`/`smg_7_0`）、按键消抖（`key`）、二进制转 BCD（`bin_to_bcd`）、38 译码显示（`ziyima3_8`）等，是数码管驱动与按键输入的入门综合练习。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| dt_smg.v | dt_smg | 动态扫描 + 内置计时：1ms 计时驱动 6 位计数器（个/十/百/千/万/十万，其中两位上限为 5），5ms 扫描轮换 `sel` 位选，段码输出 0~9 及带小数点变体 |
| smg_7_0.v | smg_7_0 | 数码管动态扫描：5ms 位选轮换，固定显示 0~5 六个数字 |
| key.v | key | 按键消抖：同步打拍消除亚稳态 + 20ms 计数，低电平稳定后输出单拍 flag 脉冲 |
| key(1).v | key(1) | 按键消抖（变体）：同步打拍 + 20ms 计数（CNT_MAX=999_999），输出 key_out 脉冲。注意：模块名带括号不规范 |
| ziyima3_8.v | ziyima3_8 | 按键加减计数显示：`sw[1]` 加、`sw[0]` 减，cnt_num 在 0~9 间循环，段码显示对应数字 |
| yima3_8.v | ziyima3_8 | 3-8 译码显示：按 `sw[2:0]` 显示 0~7，同时把 `sel` 位选拼成不同组合（文件内模块名写作 ziyima3_8） |
| top_3_8.v | top_3_8 | 顶层：例化两个 key 消抖 + ziyima3_8，用消抖后的按键控制显示 |
| bin_to_bcd.v | bin_to_bcd | 二进制转 BCD：移位加 3 算法，13 位输入循环 13 次转换为 4 个 BCD 位输出（16 位） |

## 整体功能说明

本目录集中练习数码管显示相关的多种能力：

- **动态扫描**：`smg_7_0` 与 `dt_smg` 通过 5ms 计数环形移位 `sel` 位选，轮流点亮 6 位数码管，人眼视觉暂留形成连续显示；
- **计时显示**：`dt_smg` 内置 1ms 计数进位，可显示 59:59.99 一类时间（两位带小数点），为后续秒表/倒计时打基础；
- **按键输入**：`key`/`key(1)` 完成消抖，`ziyima3_8` 用按键实现 0~9 加/减计数，`top_3_8` 将消抖与显示串起来；
- **译码/转换**：`yima3_8`（3-8 译码）与 `bin_to_bcd`（二进制转 BCD）为通用组合逻辑模块。

文件命名存在不一致：`yima3_8.v` 内模块名是 `ziyima3_8`，`key(1).v` 的模块名含括号，若加入 Quartus 工程需注意模块名规范问题（建议改名后使用）。
