# day_2 copy 内容总结

## 概述

本目录与 day_1 功能类似，练习"LED 三种效果（闪烁/流水/跑马）定时自动轮换"，采用模块化写法：状态机模块 `ztji` 每 4 秒依次点亮三个使能信号，分别驱动闪烁灯、流水灯、跑马灯三个子模块，顶层用组合逻辑选出当前 LED 输出。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| ztji.v | ztji | 状态机：4s 计时，两段式写法在 S0/S1/S2 间循环，输出 led_s_en/led_l_en/led_m_en 三个使能 |
| led_s.v | led_s | 闪烁灯：en 使能时按 TIME_s（0.5s）周期 `~led` 取反闪烁 |
| led_l.v | led_l | 流水灯：en 使能时按 TIME_l（0.5s）周期 `{led[2:0],led[3]}` 循环左移 |
| led_m.v | led_m | 跑马灯：en 使能时按 TIME_m（0.5s）周期 `{led[2:0],~led[3]}` 移位 |
| top.v | top | 顶层：例化 ztji + 三个 LED 模块，用 `case({en_s,en_l,en_m})` 选择输出 |

## 整体功能说明

`top` 顶层将时间参数（`TIME`=0.5s、`delay`=4s）通过 `parameter` 传递给各子模块，实现参数化设计：

- `ztji` 状态机以 4s 为周期，依次使能闪烁（S0）、流水（S1）、跑马（S2）；
- 三个 LED 模块各自独立计时，仅在对应使能有效时才移位/翻转；
- 顶层 `always @(*)` + `case` 根据当前使能选出闪烁/流水/跑马的 LED 值输出。

效果为：闪烁 4s → 流水 4s → 跑马 4s 循环。低有效异步复位，复位后默认输出 `4'b0001`。此目录命名/结构是 day_1 的另一种组织方式，便于对比不同分层风格。
