# day_2 内容总结

## 概述

本 day 练习**蜂鸣器发声**：用计数器分频产生不同频率的方波驱动蜂鸣器，实现"按键/拨码开关选择音调"与"自动循环播放多个音符"两种玩法，并引入了按键消抖（key）模块配合控制。目录内包含多种写法的蜂鸣器模块。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| buzzer_1.v ~ buzzer_7.v | buzzer_1 ~ buzzer_7 | 七个单音蜂鸣器：分别由 sw1~sw7 使能，各自以固定分频数（D1~D7）产生 7 个音高 |
| top.v | top | 顶层：例化 buzzer_1~7，根据 7 位拨码 `sw` 的编码选出对应音调输出到 buzzer |
| buzzer_du.v | buzzer_du | 单模块选频版：由 `sw[6:0]` 直接查表选择 7 个频率（G1~G7），不再拆成 7 个模块 |
| buzzer.v | buzzer | 按键切换音符版：按键 `key` 每按一次切换一个音高（G1~G7 循环），输出对应频率方波 |
| beep.v | beep | 自动播放版：0.5s 一个音符，自动循环播放 L1~L7 七个音符（低音序列），无需外部控制 |
| buzzer_yin.v | buzzer_yin | 音符库模块：定义低/中/高音共 21 个分频参数，节拍 0.5s，含多段被注释的曲谱（两只老虎等）示例 |
| key.v | key | 占位/空模块：仅声明 `[6:0]` 输入与输出，无实际逻辑（未完成） |
| key_buzzer.v | key | 按键消抖：同步打拍消除亚稳态 + 20ms 计数，低电平稳定后输出单拍 flag 脉冲 |
| top_buzzer.v | top_buzzer | 顶层：例化 key（消抖）+ buzzer（选音），按下按键依次切换播放 G1~G7 |

## 整体功能说明

整体围绕"让蜂鸣器按不同频率发声"展开，频率由计数器对 50MHz 时钟分频得到，`cnt_freq` 计数到对应分频数后翻转输出，占空比约 50%（`cnt_freq < (freq>>1) ? 0 : 1`）。

三条实现路线：

1. **开关选频**（`top.v` + `buzzer_1~7`，或 `buzzer_du`）：拨动不同开关直接选择音高；
2. **按键切换**（`top_buzzer.v` + `key_buzzer.v` + `buzzer.v`）：按键消抖后每按一次换一个音；
3. **自动播放**（`beep.v` / `buzzer_yin.v`）：按节拍自动循环播放大致一个音阶，为后续播放完整乐曲做铺垫。

注意：`key.v`（空模块）与 `key_buzzer.v`（消抖模块）模块名都是 `key`，若同时加入工程会产生模块名冲突，实际使用时按需二选一。
