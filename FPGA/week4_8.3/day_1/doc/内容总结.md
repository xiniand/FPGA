# day_1 内容总结

## 概述

本 day 练习 LED 三种显示效果（流水灯、跑马灯、闪烁灯）的组合实现，通过状态机定时（每 4 秒）在这三种效果之间自动轮换切换。目录中包含多套不同写法（独立模块 + 顶层整合、一体化状态机等）的版本，便于对比学习。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| led_liushui.v | led_liushui | 流水灯：0.5s 计数器，`{led[2:0],~led[3]}` 移位输出（带取反的循环） |
| led_paoma.v | led_paoma | 跑马灯：0.5s 计数器，`{led[2:0],led[3]}` 循环左移 |

## 整体功能说明

整体实现"三种 LED 效果自动轮换"：由状态机模块（`state` 或 `ztj_led`）以 4 秒为周期依次点亮三个使能信号，分别驱动流水灯、跑马灯、闪烁灯三个子模块，顶层再用组合逻辑 `case` 根据当前使能选出对应 LED 数据输出到 4 位 LED。

目录中同时保留了三种风格：

1. **模块化分层**（`led_top.v` + `state.v` + `led_liushui/paoma/shanshuo`）：状态机与显示效果分离，各模块职责清晰；
2. **参数化例化**（`top_led.v` + `ztj_led.v`）：用 `parameter` 传递时间参数，代码更通用；
3. **一体化**（`ztj.v`）：把状态机、计时器、三种 LED 效果全部集成在一个模块内，两段式状态机写法。

各版本功能等价：复位后先流水 4s → 跑马 4s → 闪烁 4s，周而复始；复位为低有效异步复位。
