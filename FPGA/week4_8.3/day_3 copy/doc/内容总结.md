# day_3 copy 内容总结

## 概述

本目录整合了**蜂鸣器播放音乐**与**按键加减数码管显示**两类功能：一方面用按键切换播放《两只老虎》和音阶上行两首旋律，另一方面用两个按键对数码管进行 0~9 加/减计数显示。目录内文件名含括号、模块名与文件名不一致等历史遗留问题较多。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| buzzer_1(1).v | buzzer_1 | 单模块选频蜂鸣器：由 `sw[6:0]` 查表选择 7 个频率（S1~S7），计数器分频输出方波（与 day_2 拆分的 buzzer_1~7 思路不同） |
| buzzer_laohu.v | buzzer_laohu | 音乐模块：en=0 时按 0.5s 节拍播放《两只老虎》（中音 Z1~Z6 音序，COUNT=108 音符），含多段被注释的备选曲谱 |
| buzzer_xx.v | buzzer_xx | 音乐模块：en=1 时按 0.5s 节拍播放低→中→高音阶上行（D1~D7、Z1~Z7、G1~G7 共 21 个音符） |
| top_buzzer.v | top_buzzer | 顶层（音乐）：按键消抖后每按一次翻转 `en`，用 `en` 在两只老虎/音阶两首曲目间切换播放 |
| key.v | key | 按键消抖：同步打拍消除亚稳态 + 20ms 计数，低电平稳定后输出单拍 flag 脉冲 |
| key_buzzer.v | key | 按键消抖（简化版）：无同步打拍，20ms 计数后输出 flag 脉冲 |
| smg_0_9.v | smg_7_0 | 按键加减显示：`key_1` 加、`key_2` 减，cnt_num 在 0~9 间循环，段码显示对应数字（文件名为 smg_0_9 但模块名写作 smg_7_0） |
| top(3).v | top | 顶层（显示）：例化两个 key 消抖 + smg_7_0，两个按键控制数字加/减并在数码管显示 |

## 整体功能说明

本目录是 day_2/day_3 功能的组合版，含两条主线：

1. **音乐播放**（`top_buzzer.v`）：按键消抖产生脉冲，翻转 `en` 使能信号；`buzzer_laohu`（en=0）播《两只老虎》、`buzzer_xx`（en=1）播音阶，`assign buzzer = en ? buzzer_xx : buzzer_lh` 选择当前播放曲目，实现"按一下切一首歌"；
2. **按键计数显示**（`top(3).v`）：两个按键分别控制加/减，经消抖后驱动 `smg_7_0` 内部计数器在 0~9 循环，段码显示到数码管。

命名注意事项：`buzzer_1(1).v`、`top(3).v` 文件名含括号，`smg_0_9.v` 内模块名却是 `smg_7_0`，加入工程编译前建议统一改名，避免误解与潜在冲突。
