# day_5 内容总结

## 概述

本 day 练习**PLL 时钟分频与数码管计时显示**：通过 `clock` PLL IP 产生 5 路不同频率时钟（c0~c4），用两个按键在 5 个频率间切换，作为数码管计时模块 `dt_smg` 的驱动时钟，从而让 6 位计时器以不同速度走动，直观展示"频率越高计时越快"。这是首次在工程中例化 PLL 时钟 IP。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 顶层：例化 clock（PLL IP）+ 两个 key 消抖 + dt_smg；按键切换 `cnt` 以选择 c0~c4 中一路时钟作为 clk_rg 驱动计时 |
| key.v | key | 按键消抖：同步打拍消除亚稳态 + 20ms 计数（delay_1=1_000_000），输出单拍 flag 脉冲 |
| dt_smg.v | dt_smg | 动态扫描 + 内置计时：1ms 计时驱动 6 位计数器（个/十/百/千/万/十万，其中两位上限为 5），5ms 扫描轮换 sel 位选，段码输出 0~9 及带小数点变体 |
| smg_dt.v | smg_dt | 一体化模块（备用）：内部 5µs 计数 + 二进制转 BCD（移位加 3）+ 6 位动态扫描显示，功能与 dt_smg 类似但写法不同 |

## 整体功能说明

`top` 顶层组织：

- `clock` PLL IP 由外部 50MHz `clk` 输入，产生 c0~c4 五路不同频率时钟（通过 `clock_inst` 例化，areset 低有效复位取反接入）；
- 两个按键经 `key` 消抖后得到加/减脉冲，控制 3 位寄存器 `cnt` 在 0~4 之间增减（越界回绕）；
- `always @(*)` + `case` 根据 `cnt` 选择 c0~c4 中一路作为 `clk_rg`；
- `dt_smg` 以 `clk_rg` 为时钟进行计时与动态扫描，把时间（如 59:59.99）显示到 6 位数码管。

切换按键即可改变驱动时钟频率，计时速度随之变化，用于验证 PLL 多时钟输出的正确性与不同频率下的计时效果。低有效异步复位。
