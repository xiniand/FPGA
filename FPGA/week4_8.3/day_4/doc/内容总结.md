# day_4 内容总结

## 概述

本 day 练习**可调刷新率的数码管动态扫描**：通过按键对刷新率进行 20 档调节（`shuaxin`），数码管扫描模块 `smg` 根据当前档位对应的刷新时间动态轮换显示 0~5，观察刷新率变化对显示效果的影响；同时复习了按键消抖与二进制转 BCD。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| key.v | key | 按键消抖：同步打拍消除亚稳态 + 20ms 计数，输出单拍 flag 脉冲 |
| shuaxin.v | shuaxin | 刷新率档位选择：`key[1]` 加档、`key[0]` 减档，cnt_num 在 0~20 间循环，输出对应档位的刷新计数值 shua（shua_0~shua_20，约 10ms~50ms） |
| smg.v | smg | 数码管动态扫描：计数到 shua 档位值即切换 `sel` 位选轮换点亮，段码固定显示 0~5，刷新率可调 |
| top.v | top | 顶层：例化两个 key 消抖 + shuaxin 选档 + smg 显示，按键改变刷新档位 |
| bin_to_bcd.v | bin_to_bcd | 二进制转 BCD：移位加 3 算法，13 位输入循环 13 次转换为 4 个 BCD 位输出（16 位，备用模块） |

## 整体功能说明

`top` 顶层把"按键消抖 → 档位选择 → 动态扫描"串联起来：

- 两个按键经 `key` 消抖后得到加/减脉冲，送入 `shuaxin`；
- `shuaxin` 在 20 档刷新计数值（约 10ms~50ms）间循环切换，输出 `shua`；
- `smg` 以 `shua` 作为位选切换周期，计数到该值就环形移位 `sel`，轮换点亮 6 位数码管显示 0~5。

调节按键可实时改变扫描刷新频率，刷新率过高/过低都会影响显示效果，用于体会动态扫描的视觉暂留原理。低有效异步复位。`bin_to_bcd` 为本目录中的通用转换模块（本例未参与顶层例化）。
