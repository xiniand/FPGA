# week6_8.17\day_4 内容总结

## 概述

本 day 练习 **乒乓缓存**实验：ROM 读出数据 → 双 RAM 乒乓（写 A 读 B / 写 B 读 A）→ UART **460800bps** 高速发送，实现连续无间隙的数据流输出。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| rom.v | rom | ROM 地址自增，例化 `rom_data` IP 输出 8 位数据 |
| ping_pong.v | ping_pong | 乒乓控制：W1/W2R1/W1R2 三态，两个 `ram_data` 交替写/读（256 深度），done_tx 驱动读地址 |
| ping_pong_3.v | ping_pong_3 | 三 RAM 乒乓**未完成草稿**（语法/状态机不完整） |
| brg.v | brg | 波特率发生器：**460800bps**（每 bit 约 108 周期） |
| tx.v | tx | 发送器：带 MODE 校验、start 上升沿检测、brg_en 门控 |
| top.v | top | 顶层：rom→ping_pong→tx |

## 整体功能说明

ROM 依次读出数据，乒乓模块在 RAM1 写满后切到写 RAM2、同时读 RAM1 发 UART，实现连续无间隙数据流；UART 用 460800 高波特率匹配数据速率。IP：`rom_data`、`ram_data`。仿真 `test.v` 为顶层仿真。
