# week6_8.17\day_1 内容总结

## 概述

本 day 综合练习 **UART 链路整合 + FIFO / RAM 缓存显示 + 按键消抖 + 乒乓缓存（pp_fifo）设计**：三个顶层分别演示 FIFO 缓存显示、RAM 缓存显示+按键回发、内部回环自测三种数据通路；`pp_fifo` 独立演示用两个 FIFO 构成的乒乓缓存。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| brg.v / tx.v / rx.v | brg / tx / rx | 9600bps；rx 带偶校验 |
| key.v / dt_smg.v | key / dt_smg | 按键消抖（20ms 单脉冲）/ 2 位动态数码管 |
| top_uart.v | top_uart | rx→FIFO→1s 定时读→数码管；key 触发发送 tx_data |
| top_uart_jf.v | top_uart_jf | rx→RAM→按键触发读→数码管并回发 |
| top_uart_zh.v | top_uart_zh | 回环（tx→rx）+ FIFO + 数码管 |
| ram_xun.v | ram_xun | RAM 地址计数封装（例化 `ram_data` IP，深度 256） |
| pp_fifo.v | pp_fifo | **乒乓缓存**：两个 `fifo_data` 组成写 A 读 B / 写 B 读 A，写满自动切换，读写并行、防溢出/防读空 |

## 整体功能说明

三个顶层各演示一种数据通路（FIFO 缓存显示 / RAM 缓存显示+按键回发 / 内部回环自测）；`pp_fifo` 独立演示乒乓缓存（含读打拍对齐、need_switch 切换）。IP：`fifo_data`、`ram_data`。仿真含 `test_top.v`（brg+tx+rx 回环）、`test_pp_fifo.v`、`test_fifo_single.v`。
