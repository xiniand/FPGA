# week6_8.17\day_3 内容总结

## 概述

本 day 练习 **IIC 读 RGB 颜色传感器**（器件地址 0xA6/0xA7）→ 比较 RGB 强度 → **WS2812 点阵**显示 R/G/B/N + UART 115200 组帧上报上位机。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| iic.v | iic | IIC 主机：100kHz，三段式状态机（含虚写 START1/ID1/ACK4），应答检测 |
| iic_test_ctrl.v | iic_test_ctrl | 主控 FSM：上电 10ms→3 次初始化写（寄存器 06/04/05）→500ms→读 9 字节（0x0D 起）存入 72 位移位寄存器 |
| uart_send_ctrl.v | uart_send_ctrl | 组帧：AA 55 + ID 53 + R/G/B 各 3 字节 + 0D 0A |
| uart_tx.v | uart_tx | UART 发送器：115200，独热码状态机，位宽可配 |
| rgb.v | rgb | WS2812C 点阵：T0H/T0L/T1H/T1L/TRST 时序，8×8 字模显示 R/G/B/N 字母 |
| top_main.v | top_main | 顶层：RGB 各 3 字节拼 24 位，比较最大色（绿>0x0007EF 判自然光）→ color_mode |

## 整体功能说明

`iic_test_ctrl` 经 `iic` 对颜色传感器写初始化寄存器再读 9 字节原始 RGB（每通道 MSB/MID/LSB 3 字节），`top_main` 做“赢家通吃”选出最大色，一路驱动 WS2812 点阵显示字母，一路经 UART（115200）发回上位机。prj 无 IP（全手写）。
