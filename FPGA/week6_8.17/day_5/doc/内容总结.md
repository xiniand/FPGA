# week6_8.17\day_5 内容总结

## 概述

本 day 练习 **DS18B20 温度采集**（1-Wire）→ 正负/整数/小数分离 → 二进制转 BCD → 数码管动态显示。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| DS18B20.v | DS18B20 | 早期版 1-Wire 主机（主/从两级状态机：复位/存在脉冲/跳 ROM/转换/读寄存器） |
| DS18B20_a.v | DS18B20_a | 新版 1-Wire 主机：IDLE/START/INIT/SKIP(CC)/CONV(44)/DELAY/READ(BE)/DATA/STOP，key 触发，返回 16 位温度 |
| temp.v | temp | 温度处理：负数取补码，分离整数 `temp_rg[11:4]` 与小数 `temp_rg[3:0]×625` |
| bin_to_bcd.v | bin_to_bcd | **加 3 移位法（Double-dabble）** 将二进制转 8421 BCD（整数 8 次/小数 14 次迭代） |
| dt_smg.v / key.v | dt_smg / key | 动态数码管 / 按键消抖（触发读取） |
| top_temp.v | top_temp | 顶层：key→DS18B20_a→temp→bin_to_bcd→dt_smg |

## 整体功能说明

按键触发 DS18B20 完成复位/存在脉冲 → 跳过 ROM(CC) → 温度转换(44，等 **750ms**) → 读暂存器(BE) → 读 16 位原始温度；`temp` 判正负并拆整数/小数，`bin_to_bcd` 转 BCD，6 位数码管显示。关键参数：1-Wire 位周期 64us、复位 480us、转换等待 750ms。
