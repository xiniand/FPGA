# week6_8.17\day_2 内容总结

## 概述

本 day 练习 **UART 自动回传**——接收 → FIFO 缓冲 → TX 空闲自动取数发回（回环），并参数化奇偶校验（`MODE`：0 无 / 1 奇 / 2 偶）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| brg.v / tx.v / rx.v | brg / tx / rx | 9600bps；tx/rx 带 parameter MODE 支持 0/1/2 校验 |
| key.v / dt_smg.v | key / dt_smg | 按键消抖（保留未用）/ 2 位动态数码管 |
| ram_xun.v | ram_xun | RAM 地址封装（新增 `wr_count` 已写入计数，读按实际写入量回绕） |
| top_uart_jf.v | top_uart_jf | 顶层：rx→FIFO→自动发送回传；rx→RAM→数码管显示 |

## 整体功能说明

相对 day_1 的改进：FIFO 非空且 `tx_busy=0` 时产生单周期 `fifo_rd_req` 读出一字节、打拍采集后自动触发 tx 发回 PC（`MODE=2` 偶校验）；另一路 rx 数据写 RAM 供数码管按 1s 显示。仿真 `test_top.v` 验证 brg+tx+rx 链路。
