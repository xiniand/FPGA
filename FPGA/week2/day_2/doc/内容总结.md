# day_2 内容总结

## 概述

本练习实现按键消抖、分频器（偶数分频与奇数分频）以及按键控制的 LED 流水灯，并通过顶层模块将按键消抖与流水灯模块例化连接成完整功能。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| key.v | key | 按键消抖：按键按下（低电平）时计数器累加约 20ms（`delay=1_000_000`，50MHz 时钟），达到阈值输出一个 `flag` 脉冲 |
| led.v | led | LED 流水灯：收到 `flag` 脉冲时对 4 位 LED 做循环左移（`{led[2:0], led[3]}`），实现单灯循环点亮；内含注释掉的打拍上升沿检测示例 |
| top_fpj.v | top_fpj | 奇数分频（默认 3 分频）：分别用上升沿/下降沿两个计数器生成 `clk_1`、`clk_2`，再相或 `clk_fpj = clk_1 | clk_2` 得到占空比 1/3 的时钟 |
| top_fpq.v | top_fpq | 偶数分频（默认 2 分频）：计数器满 `delay-1` 时翻转 `clk_fp`，得到 50% 占空比的时钟 |
| top_key.v | top_key | 顶层模块：例化 `key`（消抖）与 `led`（流水灯），将消抖脉冲 `flag` 接入 LED 的移位触发端，实现按键按一下、灯走一步 |

## 整体功能说明

系统顶层为 `top_key`：**按键消抖模块 `key`** 对机械按键去抖并产生单脉冲 `flag`；**LED 模块 `led`** 在每次 `flag` 到来时让 4 个 LED 循环左移一位，形成“按一次键，灯移动一格”的流水灯效果。

另外单独练习了分频器设计：

- `top_fpq`（偶数分频）：计数器翻转法，输出占空比 50%；
- `top_fpj`（奇数分频）：利用上升沿与下降沿两个计数器的组合，解决奇数分频占空比不对称问题。

本练习综合了**消抖**、**分频**与**流水灯**三个常用数字电路知识点。
