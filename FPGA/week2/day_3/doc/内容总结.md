# day_3 内容总结

## 概述

本练习延续 day_2，进一步练习按键消抖与 LED 流水灯的控制逻辑，同时包含若干不完整/模板性质的源码（如 `top_zxd.v` 空模板、`zxd.v` 草稿、`key_zxd.v` 缺时钟），作为课堂练习过程记录。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| key.v | key | 按键消抖：与 day_2 的 `key` 相同，按键按下累加约 20ms 后输出 `flag` 脉冲（`delay=100_000_0`） |
| key_zxd.v | key_zxd | 按键消抖变体：逻辑与 `key.v` 一致，但 `always @(posedge)` 缺少时钟信号、无时钟端口，**属未完成的草稿代码**，不可直接综合 |
| led.v | led | LED 控制：`key` 为高时 4 位 LED 循环左移（`{led[2:0], led[3]}`），否则保持，实现流水灯 |
| top_key.v | top_key | 顶层模块：例化 `key`（消抖）与 `led`，把消抖输出 `flag` 接到 LED 的移位使能端 |
| top_zxd.v | top_zxd | 空模块模板：仅 `module moduleName(ports); endmodule` 骨架，无实际功能 |
| zxd.v | zxd | 草稿代码：仅定义了 `TIME=125_000_00` 参数和空的 `always` 块（内部无语句），**未完成**，仅供学习参考 |

## 整体功能说明

可正常工作的核心链路是 `top_key`：**`key` 消抖模块**输出约 20ms 稳定后的 `flag` 脉冲，**`led` 模块**在脉冲到来时让 LED 循环左移，实现按键控制流水灯。

本 day 中还保留了若干未完成的练习文件（`key_zxd.v`、`top_zxd.v`、`zxd.v`），反映的是课堂编写过程中的中间状态，其中：

- `key_zxd.v` 与 `zxd.v` 因缺时钟/语句不完整，**不可综合、不能上板**；
- `top_zxd.v` 仅为新建模块时的空模板。

使用时建议以 `key.v`、`led.v`、`top_key.v` 为参考基准。
