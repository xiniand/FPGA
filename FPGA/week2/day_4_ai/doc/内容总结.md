# day_4_ai 内容总结

## 概述

本练习是转向灯控制系统的**规范化实现**（AI 辅助生成版）：用 3 个按键控制左转、右转、双闪，4 位 LED 流水/闪烁显示，代码带完整注释、参数清晰、采用低有效异步复位，可直接综合上板（Cyclone IV E EP4CE6F17C8）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| clk_div.v | clk_div | 时钟分频器：50MHz 计数到 `12_499_999` 产生 4Hz `tick` 脉冲（每 0.25s 一步，用于流水灯步进），低有效异步复位 |
| key_debounce.v | key_debounce | 按键消抖：两级同步寄存器（`sync_1/sync_2`）防亚稳态 + 20ms（`1_000_000` 个时钟）计数延时采样，输出稳定后的按键电平 |
| turn_ctrl.v | turn_ctrl | 转向灯控制器（无显式状态机）：2 位 `mode` 寄存器 + 组合逻辑实现空闲`00`/左转`01`/右转`10`/双闪`11` 四模式；按键上升沿检测切换模式，LED 移位寄存器实现左/右流水，双闪整体翻转；双闪优先级最高 |
| top.v | top | 顶层模块：例化 `clk_div`、3 个 `key_debounce`（左/右/双闪）与 `turn_ctrl`，将外部低有效按键取反后接入消抖，最终输出 4 位 LED |

## 整体功能说明

系统顶层为 `top`，工作流程如下：

1. **按键消抖**：3 个按键（低电平有效）取反后各经一个 `key_debounce`，两级打拍 + 20ms 延时采样，得到稳定、无亚稳态的按键电平；
2. **节拍产生**：`clk_div` 把 50MHz 分频为 4Hz 的 `tick` 脉冲；
3. **模式与显示**：`turn_ctrl` 通过按键上升沿检测在 空闲/左转/右转/双闪 四模式间切换（再按同键退出，左+右同按进入双闪），并在每个 `tick` 更新 LED：左转右→左流水、右转左→右流水、双闪 2Hz 整体闪烁。

相比 day_4 手写版，本实现代码结构清晰、注释详尽，`key_debounce` 增加两级同步防亚稳态，`turn_ctrl` 采用寄存器+组合逻辑组织，功能完整且**可直接综合上板**。
