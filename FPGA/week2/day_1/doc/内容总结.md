# day_1 内容总结

## 概述

本练习通过三个独立小模块，分别实现组合逻辑（二选一多路选择器、半加器）与基本时序逻辑（D 触发器），是 Verilog 入门的基础练习。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top.v | top | 二选一多路选择器：`sel=0` 输出 `in_a`，`sel=1` 输出 `in_b`，用 `always @(*)` + `case` 实现 |
| top_d.v | top_d | D 触发器：低有效异步复位，每个时钟上升沿将 `D` 锁存到 `Q`（`always @(posedge clk or negedge rst)`） |
| top_j.v | top_j | 半加器：`C = X & Y`（进位）、`S = X ^ Y`（和），用连续赋值 `assign` 实现；注释中还给出 `{C,S} = X + Y` 的等价写法 |

## 整体功能说明

三个模块相互独立，分别演示了 Verilog 的三种典型写法：

- **组合逻辑**：`top`（case 语句）与 `top_j`（assign 连续赋值）；
- **时序逻辑**：`top_d`（带异步复位的 D 触发器）。

该练习帮助理解组合逻辑与时序逻辑的区别、非阻塞赋值 `<=` 的用法，以及 `case` / `assign` 两种描述方式，为后续复杂设计打基础。
