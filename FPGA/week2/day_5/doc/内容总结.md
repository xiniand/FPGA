# day_5 内容总结

## 概述

本练习是转向灯控制系统的**完善版**：在 day_4 基础上修正了按键消抖（`zxd_key.v` 补全计数位宽与 `flag` 输出）并改进 LED 显示逻辑，实现右转、左转、双闪、熄灭四种模式的转向灯控制。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| clk.v | clk | 时钟分频：按 `fp=124_999_99` 计数产生约 4Hz 的 `clk_out` 节拍脉冲，供 LED 步进（与 day_4 相同） |
| top_zxd.v | top_zxd | 顶层模块：例化 `zxd_led`、`clk` 与 4 个 `zxd_key`（右转/左转/双闪/熄灭），将 4 个消抖标志与分频时钟送入 LED 控制（与 day_4 相同） |
| zxd_key.v | zxd_key | 按键消抖：**已修正**，`cnt` 扩为 20 位 `reg [19:0]`，消抖约 20ms（`delay=100_000_0`），并补上 `assign flag = (cnt == delay - 2) ? 1 : 0` 输出脉冲（相对 day_4 的修复） |
| zxd_led.v | zxd_led | LED 控制：按键优先级编码成 2 位模式（右转`11`/左转`10`/双闪`01`/熄灭`00`），在 `clk_out` 节拍下执行：熄灭、双闪（全亮/全灭翻转）、左移流水（右→左）、右移流水（左→右）；初始/复位到非全亮非全灭状态时先回到起点再流水 |

## 整体功能说明

系统顶层为 `top_zxd`，与 day_4 结构一致但逻辑更完善：

1. 4 个按键分别经 `zxd_key` 消抖（本次已正确实现 20ms 计数并输出 `flag` 脉冲）；
2. `zxd_led` 按优先级编码模式，`clk` 产生约 4Hz 节拍驱动 LED 显示：右转从右往左流水、左转从左往右流水、双闪整体 2Hz 闪烁、熄灭全灭。

**相比 day_4 的改进点**：

- `zxd_key.v` 修复了 `cnt` 位宽（1 位 → 20 位）并补全 `flag` 输出，消抖功能真正可用；
- `zxd_led.v` 的流水逻辑在 LED 处于全灭/全亮等非起点状态时会先复位到起点再开始流水，显示更规整、可正确上板演示。
