# 1 内容总结

## 概述

本 day 综合练习了 Verilog 基础组合逻辑（基本逻辑门、二选一多路选择器、2-4 译码器）与时序逻辑（计数器分频驱动 LED 闪烁），是 FPGA 入门的基础实验。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| and_gate.v | and_gate | 基本逻辑门实验：输入 A、B，输出 Y，当前生效为 `Y = A | B`（或门）；注释中保留了同或`^~`、与`&`、异或`^`、非`~` 等写法，用于对比学习各逻辑门 |
| mux2_1.v | mux2_1 | 二选一多路选择器：由选择信号 S 决定输出 `led` 取 A 还是 B（S=1 选 A，S=0 选 B）。当前用 `case` 语句实现，注释中提供了条件运算符 `?:` 和 `if-else` 两种等价写法 |
| decode2_4.v | decode2_4 | 2-4 译码器：将 2 位输入 A 译码为 4 位独热输出（00→0001、01→0010、10→0100、11→1000），用组合逻辑 `always @(*)` + `case` 实现 |
| led.v | led | 按键直控 LED：`assign led = key ? 1 : 0;`，按键按下时 LED 点亮，松开熄灭，演示最简单的外部输入输出通路 |
| cnt_1.v | cnt_1 | 分频计数闪烁：25 位计数器 `cnt` 计数到 `TIME=24_999_999`（50MHz 下约 0.5s）清零，同时 LED 电平翻转，实现约 0.5s 周期的闪烁 |
| cnt_num.v | cnt_num | 与 `cnt_1` 功能相同的分频闪烁实现，带详细中文注释，用于对照学习计数器的写法与含义 |

## 整体功能说明

本 day 从两个层面演示了 Verilog 基础设计：

1. **组合逻辑**：`and_gate`（逻辑门）、`mux2_1`（数据选择）、`decode2_4`（译码器）均通过 `assign` 或 `always @(*)` 实现，输入变化立即反映到输出，不依赖时钟。
2. **时序逻辑**：`cnt_1` 与 `cnt_num` 用 `always @(posedge clk)` 构造计数器，通过计数分频把 50MHz 系统时钟降低到约 2Hz，从而驱动 LED 以约 0.5s 周期闪烁；`led` 则展示按键直接控制 LED 的最简通路。

整体上完成了从“门电路/选择器/译码器等组合逻辑”到“计数器分频等时序逻辑”的入门练习，为后续按键消抖、数码管扫描等复杂设计打基础。
