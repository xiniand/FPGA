# 3 内容总结

## 概述

本 day 练习了**下降沿检测**的多种写法，并利用按键/开关的下降沿实现 LED 累加计数与循环移位（跑马灯），同时包含一个按键消抖（`key_k`）的示例代码。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| led.v | led | 下降沿检测 + 按键计数：将开关 `SW` 移位寄存 `sw_in[1:0]`，用 `~sw_in[0] & sw_in[1]` 检测下降沿；每检测到一次下降沿，4 位 LED 输出 `led + 1` 累加计数 |
| led_b.v | led_b | 功能与 `led.v` 相同（下降沿触发 `led + 1` 计数），仅下降沿判断写成等价的 `sw_in[1] & ~sw_in[0]`；文件内保留了大段被注释掉的定时计数（0.5s 分频）代码，用于与直接按键计数写法对比 |
| led_d.v | led_d | 下降沿 + 循环移位：复位后 `led = 4'b0001`，每按一次（下降沿）执行 `led <= {led[2:0],~led[3]}`，实现 1→2→4→8 的单灯循环点亮；注释中保留了“乘法 `led*(2**cnt_1)-1`”和“`case` 逐级累加”另外两种实现思路 |
| led_fx.v | led_fx | 与 `led_d.v` 当前生效实现一致：下降沿检测 + `{led[2:0],~led[3]}` 循环移位，代码更精简，用于对照学习同一效果的简洁写法 |
| key_k.v | key_k | 按键消抖/长按检测示例（**不完整**）：声明了 `TIME=100_000_0` 计数参数，意图通过计数判断按键稳定电平，但代码未完整实现（内部 `cnt` 未声明、`always` 块为空、`sw_k` 缺少完整时序逻辑），仅供学习消抖思路参考 |

## 整体功能说明

本 day 在上一 day“上升沿检测”的基础上转向**下降沿检测**（`~sw_in[0] & sw_in[1]` 或等价写法），并演示了两种基于按键下降沿的 LED 效果：

1. **累加计数**（`led.v`、`led_b.v`）：每按一次按键，LED 二进制计数值加 1，可观察按键次数。
2. **循环移位/跑马灯**（`led_d.v`、`led_fx.v`）：每按一次，单个亮灯沿 1→2→4→8 循环移动，并用注释给出多种实现思路对比。

`key_k.v` 属于按键消抖的初步尝试但未完成。整体上，本 day 完成了“边沿检测 + 按键交互控制 LED 状态”的进阶练习，为后续带消抖的按键模块（`key`）打基础。
