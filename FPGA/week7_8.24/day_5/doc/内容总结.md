# week7_8.24\day_5 内容总结

## 概述

本 day 在 day_4 单字节基础上完成 **EEPROM 多字节读写**：`eeprom_rw.v` 加入 16 深数据缓冲 `databuf[0:15]` 与双索引 `wr_idx/send_idx`，顶层读回数据用 FIFO 排队回发，**多字节读写完成**（git 末次提交 `ffe25ba eeprom多字节读写完成`）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top_iic_eeprom.v | top_iic_eeprom | 顶层：brg 常开 + rx + tx + `iic_0` + `eeprom_rw` + **`fifo_data`（Quartus FIFO IP）**；`tx_star=(flag | | tx_done)&&(usedw!=0)` 保证读回多字节按序回发 |
| iic_0.v | iic_0 | IIC 主机状态机，`iic_done_r`=NACK 态、`iic_done_w`=ACK2 态、`iic_done`=STOP 态产生 |
| eeprom_rw.v | eeprom_rw | 帧解析状态机升级版：`databuf[0:15]` 缓存多字节、`wr_idx` 收帧计数、`send_idx` 按 `iic_done_w` 逐字节切到 `data_temp`（**帧间 IDLE 清零索引为核心修复**）；`sendnum_cnt` 判断 ADDR/DATA 收满后进 STOP |
| brg.v / rx.v / tx.v / key.v | UART/按键 | 同前 |
| prj/ip/fifo/fifo_data | FIFO IP | 读回数据缓冲（8bit），写侧 `iic_done_r`、读侧 `rdreq=tx_star&&tx_idle` |

## 整体功能说明

UART 帧（仍为 `0xFE` 包头 / `0xEE` 包尾，含多数据字节）→ `eeprom_rw` 按 `sendnum` 逐字节收进 `databuf` → IIC 依 `iic_done_w` 逐个写；读侧 IIC 读回字节写进 FIFO，tx 空闲即逐字节回发。仿真 `test_iic.v` 发“写 5 字节(0x21,0xcf,0xad,0xdc…)”与“读 4 字节”帧验证多字节流程。
