# week7_8.24\day_2 内容总结

## 概述

本 day 练习 **IIC 主机时序状态机基础版**（`iic.v`，不含 EEPROM 业务层）：验证 100K 速率下 START / 器件地址 / 写数据 / 重复起始 / 读数据 / ACK / NACK / STOP 的时序；顶层 `top.v` 为 UART+数码管+按键的骨架雏形（多处端口未接好，属半成品）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| iic.v | iic | IIC 主机状态机：13 态（IDLE→START_1→ID_W→ACK1→SEND_ADDR_L→…→RD_DATA→NACK→STOP），含 sda/scl 三态开漏控制，`data_in`/`iic_done_r`/`iic_done_w` 输出；器件地址 `ID_1=7'b1010000`，字地址写死为 addr(默认 0) |
| iic_0.v | iic_0 | IIC 主机另一版本（带 `sendnum/recvnum`、`iic_done` 输出），本 day 未使用（`top.v` 例化的是 `iic`） |
| top.v | top | 顶层骨架：按键→`iic` 触发读写、UART rx→FIFO→tx、`dt_smg` 数码管显示，但 `tx_star`/`data`/`rst` 等大量端口未接好，未形成完整流程 |
| brg.v / rx.v / tx.v | 波特率发生器/串口收发 | UART 联调基础件，9600 波特率 |
| dt_smg.v / key.v | 数码管扫描 / 按键消抖 | 6 位动态扫描（含小数点段码）、20ms 消抖单脉冲 |

## 整体功能说明

`top` 内按键脉冲 `flag` 直接触发 `iic` 做一次读写（写地址固定 0x00，读回数据进 `data_in`）；UART 与 FIFO、数码管部分仅为预留。关键参数：50MHz 时钟、IIC 100K（delay=500、Q_MID/MID/TQ_MID 分时点）、器件地址 0xA0/0xA1。仿真 `tb_iic.v` 用按键触发“写 0xA8+0x00+0xA5”和“读回 0x5A”两段流程。
