# week7_8.24\day_4 copy 内容总结

## 概述

本目录是与 day_4 平行的**简化方案**：顶层加入按键触发读、`eeprom.v` 改为更直接的三段式状态机、`iic_0.v` 增加独立 `waddr` 输入口（区别于 day_4 用 `data_i_iic` 传地址的版本）。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top_iic_eeprom.v | top_iic_eeprom | 顶层：brg 常开 + key + rx + tx + `iic_0` + `eeprom`；`iic_done_any = iic_done_r | iic_done_w | iic_done` 合并完成信号 |
| iic_0.v | iic_0 | IIC 主机，**多一个 `waddr` 口**（字地址/第一个数据字节），与 `data_i_iic`（后续字节）分离，接口更明确 |
| eeprom.v | eeprom | EEPROM 控制状态机（IDLE→WR_START/WR_WAIT→RD_START/RD_WAIT→TX_START/TX_WAIT）；写 = UART 1 字节→IIC 写（sendnum=2：waddr+data，`waddr` 固定 0x00）；读 = 按键→IIC 读 1 字节→tx 回发；含 `rd_pending` 按键锁存、`din_vld_r` 打拍防竞争 |
| brg.v / rx.v / tx.v / key.v | UART/按键 | 同前 |

## 整体功能说明

写流程“UART 1 字节 → EEPROM 写（固定地址 0x00）”、读流程“按键 → 读 0x00 → tx 回发”；无帧协议（不用 0xFE/0xEE），业务更简单直接。与 day_4 的关键差异：`eeprom.v`（而非 `eeprom_rw.v`）与 `iic_0` 的 `waddr` 口。sim 目录为空。
