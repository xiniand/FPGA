# week7_8.24\day_4 内容总结

## 概述

本 day 完成 **IIC + EEPROM 正式联调——单字节读写**：由 UART 帧命令驱动（`eeprom_rw.v` 解析帧协议），读回数据经 UART TX 回传 PC，**上板验证通过**。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| top_iic_eeprom.v | top_iic_eeprom | 顶层：brg 常开 + rx + tx + `iic_0` + `eeprom_rw`；`iic_done_r` 时把 `data_out` 打拍到 `tx_data_rg` 再送 tx |
| iic_0.v | iic_0 | IIC 主机状态机（同 day_3 版接口：`sendnum/recvnum/data_i_iic`），0xA0/0xA1、100K |
| eeprom_rw.v | eeprom_rw | UART 帧解析状态机：`0xFE` 包头 → rw → sendnum → recvnum → addr → data → `0xEE` 包尾；`iic_start` 在 STOP 态拉高，通过 `data_temp` 切换先发地址再发数据 |
| brg.v / rx.v / tx.v | UART | 9600 波特率 |
| key.v | key | 按键消抖（本 day 顶层未使用） |

## 整体功能说明

PC 发帧 → rx → `eeprom_rw` 解析并配置 `rw_ctrl/sendnum/recvnum/data_i_iic` → `iic_0` 执行 I2C 事务（写 = 0xA0+addr+data 两字节；读 = 0xA0+addr+重复 START+0xA1+读 1 字节 NACK）→ 读回 `data_out` → tx 回发。**帧协议**：包头 `0xFE`、包尾 `0xEE`；写帧 `FE 00 sendnum recvnum addr data EE`，读帧 `FE 01 sendnum=1 recvnum=1 addr EE`。仿真 `test_iic_m.v` 挂 `eeprom_24c02.v` 行为模型（256B 内存、START/STOP/ACK、0xA0 写/0xA1 读），验证写 0xAA 后读回。
