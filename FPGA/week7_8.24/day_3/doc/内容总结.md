# week7_8.24\day_3 内容总结

## 概述

本 day 练习 **IIC 主机状态机的独立细化与多字节控制参数化**（`sendnum` 发送字节数 / `recvnum` 接收字节数），为 EEPROM 读写做铺垫；目录仅含 IIC 模块与纯仿真，无顶层。

## 源文件与模块

| 文件 | 模块名 | 功能说明 |
| ------ | -------- | --------- |
| iic_0.v | iic_0 | IIC 主机状态机（11 态），带 `sendnum/recvnum` 计数与 `iic_done_r/iic_done_w/iic_done` 完成信号 |
| iic_0_1.v | iic_0_1 | IIC 主机改进版：在 `ACK2` 处 `sendnum_cnt+1`、`NACK` 处 `recvnum_cnt+1`，支持按 `sendnum/recvnum` 连续写/读多字节；含 `iic_start_rg` 边沿打拍 |

## 整体功能说明

纯 IIC 主机模块仿真（`sim/test.v`），例化 `iic_0_1`，`rw_ctrl=0`、`sendnum=3`、`recvnum=0` 模拟一次“写 3 字节”事务，`iic_done_w` 后自增写数据（0x11,0x22,0x33…）。关键参数：器件地址 `id_w=0xA0/id_r=0xA1`、IIC 100K、50MHz 时钟。
